KEY DIFFERENCES

1. STATIC AND DYNAMIC TYPING

Statically typed languages:
Type rules are checked primarily before the program runs.

Examples:

  • TypeScript

  • Java

  • C

  • C++

  • C#

  • Go

  • Rust

Dynamically typed languages:
Types are associated primarily with runtime values and checked while the program runs.

Examples:

  • Python

  • JavaScript

2. STRONG AND WEAK TYPING

Strongly typed languages:
Usually prevent unrelated types from being combined without an explicit conversion.

Examples:

  • Python

  • TypeScript

  • Java

  • C#

  • Go

  • Rust

Languages with weaker or more permissive conversions:
Allow more implicit conversions that may produce unexpected results.

Examples:

  • JavaScript

  • C

Strong and weak typing are informal terms and may be defined differently depending on the discussion.

3. COMPILED AND INTERPRETED EXECUTION

Native compiled languages:
Usually translate directly into machine code before execution.

Examples:

  • C

  • C++

  • Go

  • Rust

Virtual-machine languages:
Compile into intermediate instructions executed by a runtime.

Examples:

  • Java

  • C#

Interpreted or runtime-compiled languages:
Use an interpreter, bytecode engine, or just-in-time compiler.

Examples:

  • Python

  • JavaScript

Source-to-source compiled language:
TypeScript is checked and converted into JavaScript before execution.

4. MEMORY MANAGEMENT

Manual memory management:

  • C

  • Much of C++

Goal: Give the programmer direct memory control, while increasing the risk of leaks and invalid memory access.

Garbage-collected memory:

  • Python

  • JavaScript

  • Java

  • C#

  • Go

Goal: Automatically reclaim memory that is no longer being used.

Ownership-based memory:

  • Rust

Goal: Provide memory safety without requiring a traditional garbage collector.

5. COMMON PROGRAMMING STYLES

Procedural programming:
Organizes programs around instructions and functions.

Common in:

  • C

  • Go

  • Python

Object-oriented programming:
Organizes programs around objects containing data and behavior.

Common in:

  • Java

  • C#

  • C++

  • Python

  • TypeScript

Functional programming:
Emphasizes functions, immutability, and reduced side effects.

Supported by:

  • Python

  • JavaScript

  • TypeScript

  • Java

  • C#

  • Rust

Concurrent programming:
Emphasizes coordinating multiple tasks.

Strong support in:

  • Go

  • Rust

  • Java

  • C#

IMPORTANT DISTINCTIONS

  1. Static does not mean strong.
    A language may check types before execution while still permitting unsafe or implicit conversions.

  2. Dynamic does not mean weak.
    Python is dynamically typed but generally prevents unrelated types from being combined automatically.

  3. Compiled and interpreted are not strict opposites.
    Many languages use a combination of compilation, interpretation, bytecode, and just-in-time compilation.

  4. A language and its implementation are different.
    The same language may be executed by different compilers or runtimes.

  5. Typing describes several separate properties.
    Static, dynamic, strong, weak, explicit, inferred, nominal, and structural typing answer different questions.

  6. No programming language is best for every task.
    Language choice depends on performance, safety, development speed, ecosystem, platform, and project requirements.
